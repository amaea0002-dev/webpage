Security

Built for firms that handle
sensitive client data.

Amaea is designed from the ground up to meet the security expectations of FCA-regulated financial services firms.

UK & EU Data Hosting

All client data is hosted on UK and EU infrastructure. Amaea never transfers data outside of these jurisdictions.

Encryption at Rest & in Transit

All data is encrypted at rest using AES-256 and in transit using TLS 1.3. Encryption keys are managed with annual rotation.

GDPR Compliance

Amaea operates as a data processor under your firm's GDPR framework. We process client data solely on your instructions and never use it for any other purpose.

Access Controls

Role-based access control, audit logging of all user actions, and session management with automatic timeout.

Our security commitments

These are the standards we hold ourselves to. Where we have a target date, we've stated it openly.

  • ✓ SOC 2 Type II certification in progress, target: Q1 2028
  • ✓ Annual penetration testing by an independent third party
  • ✓ Incident response plan with 72-hour breach notification (GDPR Article 33)
  • ✓ Sub-processor list published and maintained
