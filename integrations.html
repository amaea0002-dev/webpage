Core integrations

Built for the systems IFA firms actually use.

Intelliflo
Available now

The dominant CRM for UK IFA firms. Amaea reads your client data, review history, and document records from Intelliflo automatically — no manual uploads, no double-entry. Changes in Intelliflo sync to Amaea daily.

  • ✓ Client records and review history
  • ✓ Document status and file references
  • ✓ Adviser assignments and client ownership
  • ✓ Automatic daily sync
Microsoft SharePoint
Available — Professional & Scale

Most IFA firms store suitability letters, fact finds, and client correspondence in SharePoint. Amaea reads these documents directly, classifies them by client and document type, and updates compliance records without anyone moving a file.

  • ✓ Automatic document classification
  • ✓ Suitability letters, fact finds, SOAs
  • ✓ Client matching by name and reference
  • ✓ No file migration required
Salesforce
Available — Professional & Scale

For firms that use Salesforce as their primary CRM. Amaea connects to your Salesforce instance to read client records, review schedules, and task notes, keeping compliance data in sync without duplicating your workflow.

  • ✓ Client and account record sync
  • ✓ Review and task history
  • ✓ Bi-directional compliance flag sync
  • ✓ Custom field mapping
AI Document Import
All plans · No CRM needed

Not yet connected to a CRM? Drop your existing documents directly into Amaea. The AI reads each file, identifies the client, classifies the document type, and files it against the right record — no manual data entry.

  • ✓ PDF, JPG, PNG document support
  • ✓ AI classification and client matching
  • ✓ Resolves missing document flags automatically
  • ✓ Ideal while Intelliflo integration is being set up
Dynamic Planner
Coming soon

Risk profiling and cashflow planning data from Dynamic Planner synced to Amaea, keeping suitability records current without duplicating assessments.

DocuSign
Coming soon

When a client signs a document via DocuSign, Amaea updates the compliance record automatically. No manual confirmation, no document chasing.
