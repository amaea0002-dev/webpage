What Amaea will do on day one.

Each feature is grounded in a specific FCA rule. No "AI-powered everything". Concrete systems with concrete citations.

Client journey · 17 doc types

Fact find, suitability report, ATR, Consumer Duty outcome, vulnerability assessment, AML CDD: the system knows which are missing and which expire when.

Consumer Duty (PS22/9)

Per-outcome assessment record. Vulnerability re-assessments raised the day a client crosses the 12-month FG21/1 threshold.

AI assistant with audit trail

RAG against an 11,645-chunk FCA corpus. Every response carries prompt + response SHA-256s so the audit trail is bit-for-bit reproducible.

Annual review sweep (COBS 9.5)

A nightly cron evaluates every overdue review against COBS 9.5's actual sufficiency test, with the reasoning attached to the audit log.

RMAR sections B/D/E/G/H

Pre-filled from live data. DISP 1.6 cross-check on complaints. Each section exports as CSV ready for GABRIEL.

Integrations · OAuth + AES-256-GCM

Intelliflo, SharePoint nightly sync. Salesforce, Curo, Assureweb on the same pattern. Tokens encrypted at the app layer with the key isolated in a Vercel env var.
